# Course coverage

Which module of *Writing in the Sciences* each part of the plugin comes from.
Useful if you are taking the course and want the plugin to reinforce a specific
unit, or if you want to check a rule against its source.

The course has 8 units and 54 teaching modules, plus 8 optional demo-edit
sessions in which a full student essay is edited end to end.

## Not covered here

**The demo edits.** Eight sessions of end-to-end essay editing. The *method* they
demonstrate — structure first, then line by line — is encoded in
`sciwrite-prose/SKILL.md`, but watching someone edit a real essay for twenty
minutes teaches things a written procedure cannot.

**The exercises.** The course's practice material is where the learning actually
happens. This plugin is a reference and a tool, not a substitute for doing the
work.

**Systematic reviews and meta-analyses.** Named in module 7.1 as distinct from
narrative reviews, and deliberately out of scope: they carry methodological
requirements (search protocols, PRISMA, statistical pooling) beyond what a
writing plugin should pretend to cover.
